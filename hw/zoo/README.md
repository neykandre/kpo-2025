# Анализ SOLID в мини-дз Zoo

Этот документ описывает, как принципы SOLID реализованы в проекте.

## Применение SOLID

| Файл                                    | Принципы     | Описание                                                                                                                                                                           |
|-----------------------------------------|--------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `Animal`                                | **S**, **L** | **S**: Отвечает только за представление животного, поведение определяют его потомки. **L**: Дочерние классы (`Predator`, `Herbo`) могут подменять `Animal`, не нарушая логику.     |
| `AliveInterface` и `InventoryInterface` | **I**        | **I**: Определяет контракт отдельно для живых существ и отдельно для инвентаризационных объектов, так как животные могут имплементировать оба этих интерфейса, а вещи только один. |
| `Zoo`                                   | **S**, **D** | **S**: Управляет зоопарком, не отвечая за ввод-вывод или фабрики. **D**: Завязан на абстракции (`Animal`), а не на конкретных классах.                                             |
| `PredatorFactory` и `HerbivoreFactory`  | **O**        | **O**: Можно добавить новых животных без изменения существующего кода.                                                                                                             |
| `ConsoleMenu`                           | **S**        | **S**: Отвечает только за ввод-вывод, не управляет зоопарком.                                                                                                                      |
